Move Mina to Saturday Class B?

Mina would move from Sunday Class A to Saturday Class B.

The teacher of Saturday Class B will see Mina's progress.

The teacher of Sunday Class A stops seeing Mina in that class when the move happens, not before.

Cards, stars and finished lessons stay with Mina.

The move happens after 2 days. Anyone in the family can cancel before then.

  • Mina's name, picture and level
  • When Mina practiced, minutes each day and days in a row
  • Quests done and how many answers were right
  • Cards earned, letters learned and letters that need practice
  • Level check results
  • Progress on homework from Saturday Class B
  • When Mina joined the class and when progress was last saved
  • The answer Mina picks on a note from the teacher

Nothing else from the app is shared with the teacher.
