# Shell/Offline — grown-up pages need the internet; learning does not (wireframe v1)

Spec: `docs/specs/F-APP-001-persona-app-shell.md` §3.4, §3.12
Audience: **parent or caregiver, teacher** (grown-up page requested offline); may be seen by a learner who followed a grown-up link, so the copy is neutral
Artifact: `dist/grown-ups-offline.html`, generated by `apps/mobile/scripts/pwa-postbuild.mjs` and precached (A-2); a self-contained static page (inline styles from tokens, tiny locale pick, no other script)

## Scenario (Given-When-Then)

Given: a device that has the learner app's service worker and no network
When: a grown-up page (`/signin`, `/parent`, `/teach`, `/account`, `/start`) is opened
Then: instead of a browser error or the wrong app, a short page explains that grown-up pages need the internet and offers the one thing that works offline: learning

## Screen goal

"Get back to learning while offline." (secondary: try again)

## Box diagram

```
+-----------------------------------+
|                                   |
|      [no-signal outline]          |
|   "You're offline" (title)        |
|   1-2 lines: grown-up pages need  |
|   the internet; learning works    |
|   offline                         |
|                                   |
|   [[ BACK TO LEARNING ]]          |  -> /
|   [ Try again ]                   |  -> reload this URL
|                                   |
+-----------------------------------+
```

- No Hoya illustration asset (the page must stay self-contained and tiny); a simple outline shape only.
- Text from `console.offline` in every shipped locale, chosen by the browser languages; English otherwise.

## Interaction points

- [[ BACK TO LEARNING ]] → learner app `/` (precached, works offline)
- [ Try again ] → reloads the requested grown-up URL (served from the network when back online)

## Navigation graph

Enter from: any offline navigation to a grown-up path (service worker `precacheFallback`) · `shell/grown-up-lock` PIN path return while offline · `onboarding/welcome-personas` persona buttons while offline
Exit to:    learner app `/` · the requested grown-up page (when online)

## States

- **success**: as drawn (this page is itself the error state of grown-up pages).
- **empty**: not applicable.
- **error**: the page is precached; if the worker is missing (first visit offline) the browser's own offline page shows, as today.

## Data needs

- reads: `navigator.languages`
- writes: nothing

## Open questions

- None blocking. If the owner wants the learner's chosen UI language instead of the browser language, the page could read the learner's device locale key; default: browser languages (no storage read on this page).
