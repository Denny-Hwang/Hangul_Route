### 4.2 Exact deck rules

Common terms: **route quests** = `routeCatalogOf(CATALOG)` (`packages/content-schema/src/catalog/route-catalog.ts:15`), lesson quests only (`grid`), `playable` only, in route order. **m(block)** = the catalogue minutes of a quest or story (`CatalogQuest.minutes`, `CatalogStory.minutes`), an activity's own minutes, 1 per quiz round, and 1 per two slides for `revisit`, `jamo-set`, `cards` and `word-review` (section 4.4). **T** = the chosen length.

**Fill rule `fillToLength(candidates, T, review)`** (pure):
1. Take candidate content blocks in order while `running + m(block) <= T`; the first candidate is always taken (a lesson is never empty).
2. If `review` and `T - running >= 5`, add `{ kind: 'quiz', from: 'previous', rounds: 4 }` (4 minutes). The resolver does not count taught items: it reads the catalogue only, and Stage 3-7 quests carry `teaches: []` (`catalog/data.ts`), so a count there would drop the quiz from every upper-stage preset. The builder already skips a quiz whose scope has fewer than 4 letters or words (`scope-too-small`, `deck-builder.ts:644-656`), so the decision stays pure and gives the same blocks on every surface.

### 4.4 Rule 12 amendment (minutes)

F-TCH-004 §3.3 rule 12 adds: a `revisit`, `jamo-set`, `cards` or `word-review` block counts `ceil(slides / 2)` minutes for its non-quiz slides (its quiz slides keep 1 each) (**LV-2**). Quest and story minutes stay the catalogue's, and they already include the quest's or story's own quiz and check slides: the 1 minute per quiz slide counts only quiz slides outside a quest's or story's own slides (LV-0b observation O1: before LV-2 the 20-minute Hangul week 1 deck previewed as "about 38 minutes" because the 19 Match Sound rounds inside its three quests were counted again). A `story` block counts its catalogue minutes (on the presenter `LectureStory.minutes`, the same number the console shows as `CatalogStory.minutes`; before LV-2 it counted 0 plus its check slides), and a story inside a quest or a story episode adds none of its own. Observation O1 and the story-block count are built in **LV-2** (#726 built them on its rebase onto LV-0b while DN-0 moved them to LV-M1; both merged on 2026-10-17, review log). The rest of this section is row **LV-M1** (section 18): a `vocab` block counts `ceil(word slides / 2)` plus its quiz slides (today 0 plus the quiz). A deck that has slides never says "about 0 minutes": the estimate is at least 1. So a preset's preview minutes never exceed the length on its card and are no less than that length minus 5, except Hangul week 1 at 30 minutes, which section 4.2 H gives as 24 (tested in `lecture-presets.test.ts` and `deck-builder.test.ts`; on the shipped bundle the presenter's minutes equal the console's catalogue minutes for every preset but Word review, whose console count is the upper bound below). The console's `aboutMinutes` (`lecture.ts:197`) mirrors this from the block size (letters, cards, words) and the catalogue's story minutes so both sides round the same way. For a `word-review` block the console counts the full card cap (10 or 20) and is an upper bound: the presenter shows a card only for a word no earlier block of the deck showed (`seenWords`) and only for the words the review actually holds, so its estimate can come out lower, never higher (section 4.3: a difference is expected and is not shown as an error).

### 18.2 The way back (LV-M1, LV-3)

Every presenter screen has exactly one visible way back, top-left or beside the primary action, and the browser or phone back does the same thing:

| Screen | Visible way back | Browser or phone back |
|---|---|---|
| Presenter home | **Back** link, top-left (section 7 item 3): `history.back()` (1 s fallback to `/`) when this tab has an app page before `/present`, else a link to `/`, which is the case for every new tab the console, All lessons and E5 open | leaves `/present` (the browser's own back) |

### 18.3 One grouped chooser for Customize (LV-3 presenter, LV-4 console)

### 18.4 Languages on the big screen (LV-3, LV-4)

The session chips are gone; the presenter home and start screen carry the **Display (Aa)** control, which changes the device language and text size (and so changes them for the learner app on the same device, by design).
