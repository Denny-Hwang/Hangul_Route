# content/fixtures/

테스트용 고정 콘텐츠. 실제 학습 컨텐츠(`content/episodes/`, `content/cards/`)와 분리한다.

- R2 (Content Validator) 의 테스트 인풋
- `packages/content-schema` 의 zod 테스트
- `packages/test-utils` 에서 fixture factory 로 래핑하여 사용

실전 데이터가 아닌 최소 예시만 유지 (각 스키마 당 1-2 개).
- `curriculum-lint/`: F-CURR-002 §9.3 lint bundles (row CM-7). Each file is a small content tree (`files`, keyed by `content/...` path) with the findings its rule expects (`expect`: rule, severity, file, path), read by `packages/content-schema/src/__tests__/curriculum-lint.test.ts`. `.pass` bundles expect none of their own rule's findings: a bundle is clean for its rule only, and its files may break other rules. `learner` (in the review-copy bundles) holds learner messages by their `packages/i18n` file. `.report` bundles hold the expected rows of the report-only rules. Hangul stays inside `ko` fields, as the content language policy scans these files too. Generated by hand-checked helpers, not real content.
